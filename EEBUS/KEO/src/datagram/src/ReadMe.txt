SPINE Datagram

Requirements
------------
The databinder requires Python 3 and the Python 3 version of jinja2. On Ubuntu, these can be
installed via apt:

$ sudo apt install python3 python3-jinja2

Alternatively, jinja2 can be installed via pip. Make sure to use the Python3 version of pip.

You will also need generateDS:

$ sudo pip install generateDS==2.28b

It's important (for now) to use this exact version. See Redmine #2185 for details.
