virtual keo_datagram::xs_unsignedLong keo_spine::SendServiceInterface::sendPendingDatagram ( DatagramRecord &  datagramRecord)
pure virtual

Send a datagram with an expected response.

Either, the global default timeout DeviceDefinition::DatagramTimeoutDelay or the timeout the remote feature has defined in its keo_datagram::NetworkManagementFeatureDescriptionData is used.

Attention: Datagrams sent with this method expect a response. Received responses are handled in handlePendingDatagramResponse(DatagramRecord, DatagramMemo).

Calling this method sets transportId in the DatagramRecord to the ID of the connection the datagram has been sent on.

The msgCounter returned by this method should match the msgCouter of the datagram that has been passed in. Else, the sending is considered failed.

Parameters
datagramRecorddatagramRecord to send with an expected response
Returns
messageCounter, which is greater zero if sending was successful
