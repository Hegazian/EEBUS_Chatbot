Detailed Description

This namespace contains SHIP Stack related classes.

Ship Stack Smart Home IP (SHIP) describes an IP based approach for interoperable connectivity of smart home appliances, which covers local SHIP nodes in the smart home as well as SHIP web services and remote SHIP nodes.
