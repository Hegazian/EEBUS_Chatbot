Detailed Description

X509Certificate wraps OpenSSL's X509 struct.

The class provides convenience methods to retrieve information from the underlying certificate.

std::string keo_ship::X509Certificate::getSki ( ) const

Get the SKI.

If it is not set, an attempt is made to extract the SKI from the certificate. If this fails, an empty string is returned. Future versions of this class might have a fallback method to compute the SKI from the certificate's public key, but for now, we assume that the certificate contains an SKI that can be extracted from it.

Returns
the SKI, empty string in case of error.
