Detailed Description

A base class for server features.

This extends the generic feature with binding and subscription handling.

Note, that when you feature is supposed to support subscriptions and bindings, you need to overwrite allowSubscription() and allowBinding().

If you need to react on DetailedDiscoveries and/or DestinationList updates, you can override onDetailedDiscovery() and/or onRemovedDevices().
