virtual void DeviceCallbackListener::onDetailedDiscoveryFailed ( const TransportId &  transportId)
virtual

Callback to signal a failed detailed discovery read on this transport connection.

The SmartDevice sends a initial read of the detailed discovery on a new transport connection to gather the information of the peer device. If this detailed discovery fails, the connection is not usable.

This callback is used if the device is a main device

See also
SpineLink#setMainDevice(SmartDevice)
