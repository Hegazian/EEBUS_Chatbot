Detailed Description

This module offers an example implementation of the SHIP Security Handler interface.

This implementation is not suitable for use in production. It is only meant to show one simple way of implementing the methods from the interface keo_ship::ShipSecurityHandler.

The used trust store writes all trust entries in a human-readable JSON file.

See also
keo_ship::ShipSecurityHandler
