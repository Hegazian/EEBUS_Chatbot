Detailed Description

This class defines an abstract interface for SPINE connection handling.

The interface is to be implemented by an application. It is called by a 'transport connection unit'. A SPINE connection is defined as a physical transport connection which is ready to be used for SPINE data exchange. A SPINE connection is uniquely identified by a so called 'interface ID'.
