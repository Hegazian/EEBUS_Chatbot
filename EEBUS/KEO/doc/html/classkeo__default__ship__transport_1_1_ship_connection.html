virtual keo_ship::TrustLevel keo_default_ship_transport::ShipConnection::getTrustLevel ( ) const
pure virtual

Retrieve the trust level to the remote SHIP node of the current SHIP connection.

Note: SHIP is based on mutual trust. I.e. different trust level may be assigned to each other. This method returns exclusively the trust level that "my SHIP node" has assigned to "the other SHIP node".

Returns
Trust level value assigned to the remote SHIP node.
