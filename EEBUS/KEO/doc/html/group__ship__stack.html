Detailed Description

Smart Home IP (SHIP) stack API.

Implements functions and callbacks for data message transfer and connection handling to other nodes.

Callback order (simplified, see SHIP Specification for details)

onConnect() onTrustCertificate() onDataExchangeEnabled() onMessage() onClose()

Please note that, depending on the situation, not all callbacks are necessarily called. This might depend on e.g. if it is an incoming or an outgoing connection.
