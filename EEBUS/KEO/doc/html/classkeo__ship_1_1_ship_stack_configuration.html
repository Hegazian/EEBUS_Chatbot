void keo_ship::ShipStackConfiguration::setSessionCacheSize ( std::uint32_t  t)
inline

Sets the size of the internal session cache of the OpenSSL context and the size of the client cache to t.

This value is a hint and not an absolute value. Old sessions will be removed when the next time a session shall be added. This removal is not synchronized with the expiration of sessions.

Set to 0 to disable session caching.

tSession cache size.
