Detailed Description

Constructor & Destructor Documentation

keo_util::Timer::Timer ( TimerHandlerInterface *  timeoutHandler)

Creates a new per-process interval timer.

The ID of the new timer is returned by timerId() This ID is unique within the process, until the timer is deleted. The new timer is initially disarmed.

Parameters
timeoutHandlerHandler interface of the invoked handler when the timer expired.
keo_util::Timer::~Timer ( )

Deletes and disarms the timer.

If the timer was armed at the time of this call, it is disarmed before being deleted.
