Detailed Description

ShipDiscovery offers an API to announce own services and status on the network and to discovering services and statuses announced by other remote nodes.


Example discovery service data:
Service instance name:

1 "Dishwasher Bosch SMI69T45EU._ship._tcp.local."
2  \_________________________/ \________/ \___/
3  | | |
4  serviceInstanceLabel | |
5  serviceType |
6  serviceDomain


Service TXT records:

1 Key Value Example Runtime Behaviour Required
2 
3 register Boolean register=true Static Mandatory
4 brand String with brand brand=Bosch Static Optional
5 type String with device type type=Dishwasher Static Optional
6 model String with model model=SMI69T45EU Static Optional

static std::string keo_ship_discovery::ShipDiscovery::createUriWithIpAddress ( const ShipService &  shipService)
static

Returns an URI with resolved IP address (IPv6 link-local addresses are extended by interface).

Examples: wss://192.168.0.1:4711/ship/ (IPv4) wss://[fe80::a00:27ff:febc:9797%25eth0]:4711/ship/ (IPv6 link-local) wss://[2001:db8:85a3::8a2e:370:7334]:4711/ship/ (IPv6 global)

Connecting to an IP address breaks ServerNameIndication (SNI). Use with care!
