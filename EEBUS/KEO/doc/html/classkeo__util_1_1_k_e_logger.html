Detailed Description

KELogger A class providing logger functionality for the KEO Framework.

It is implemented in a non blocking way to minimize the influence of log messages and timings on the KEO Framework functionality.

For the user there is a consumer interface

See also
KELogger::ConsumerInterface that can be used to map the KEO Framework log messages to any logger used by the customer.

By default a simple console consumer

See also
KELoggerConsoleConsumer is delivered. This consumer can be configured via a simple config file and produces colored console output. For more information please refer to
KELoggerConsoleConsumer.
